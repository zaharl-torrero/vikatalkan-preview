# Виктория Талкан — концепция нового сайта

Редизайн https://www.vikatalkan.com/ по аналогии с «Порядком» и Sport Town. Статический сайт, всё для публикации лежит в `dist/`, сборка не нужна.

## Просмотр

`Запустить сайт.cmd` или `python -m http.server 8769 --bind 127.0.0.1 --directory dist`, затем http://127.0.0.1:8769/

На GitHub пока не выложен — ждёт одобрения.

## Что изменилось

- Сохранены фирменные цвета (тёмно-синий + латунь) и пара шрифтов Golos Text / Noto Serif Display; фон стал тёплым, типографика — крупнее и свободнее.
- Плавающее стеклянное меню: прячется при прокрутке вниз, темнеет над тёмными секциями, подсвечивает текущий раздел; мобильное меню.
- Hero: фото в арке, плашки с цифрами, бегущая строка, анимация появления заголовка.
- «Вторая скорость»: переключатель I / II скорость — меняется описание и шкала нагрузки на владельца, восемь элементов системы «включаются».
- «Симптом → причина»: раскрывающийся список (работает и без JavaScript), цепочка контуров компании с бегущей подсветкой.
- Форматы работы — стопка карточек, которая складывается при прокрутке.
- Результаты — бенто-сетка, счётчики, график «было 21,45 → стало 31,15 млн ₽».
- Таймлайн «Обо мне», карточки выступлений, акцент в принципе работы.
- Форма с выбором темы (бизнес / выступление). Кнопки «Пригласить как спикера» сразу выбирают нужную тему.

## Содержание и ограничения

Все тексты, цифры, фото и контакты взяты с действующего сайта 24.11.2026, ничего не добавлено. Шрифты и фото хранятся локально, внешних скриптов и аналитики нет.

Форма не отправляет данные на сервер: она копирует готовый текст и открывает чат @vika_talkan в Telegram, либо готовит письмо на vika.talkan@gmail.com. На действующем сайте форма отправляет заявку сама; при переносе нужно решить, куда её подключить. «Кабинет клиента» с действующего сайта в концепцию не перенесён.

Учитывается системная настройка уменьшения движения.

## Проверка

`node tests/check.mjs` при запущенном сервере. Использует Playwright из проекта «Порядок» и локальный Chromium. Проверяет ширины 360–1920 px, переполнение, загрузку фото, переключатель скоростей, раскрывающийся список, выбор темы и проверку полей формы, переход в Telegram и копирование текста, мобильное меню, счётчики, появление блоков, ошибки JavaScript и чтение без JavaScript. Скриншоты — в игнорируемой `tmp/check/`.
